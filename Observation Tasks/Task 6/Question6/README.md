# Node.js Built-in Modules

Node.js modules are reusable blocks of code whose existence does not accidentally impact other code. Node.js has a set of built-in modules which you can use without any further installation.

### 1. `os` (Operating System) Module
Provides operating system-related utility methods and properties. It is used to get information about the computer's OS, like free memory, user info, platform, etc.

### 2. `path` Module
Provides utilities for working with file and directory paths. It is useful for constructing reliable file paths across different operating systems (Windows uses `\` while Mac/Linux use `/`).

### 3. `fs` (File System) Module
Allows you to work with the file system on your computer. Common uses include reading files, creating files, updating files, deleting files, and renaming files.
